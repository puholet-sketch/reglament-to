# Шаблон бренда / модели

Каждая марка живёт в `brands/<slug>/` (пример: `exeed-rx`).

## Обязательные файлы

| Путь | Назначение |
|---|---|
| `index.html` | Публичная страница (ОУД4-стиль: Unbounded + Onest, crimson) |
| `assets/css/style.css` | Стили (можно копировать с `exeed-rx` и править токены) |
| `assets/js/main.js` | Nav, timeline, tabs, tooltips, reveal |
| `assets/img/` | Hero + чеки/заказ-наряды для секции отчёта |
| `docs/` | Исходники: регламент, пороги/подъёмник, чеки, СТС (локально) |
| `.ai/CONTEXT.md` | Факты по авто (VIN, пробег, пакет ТО) |
| `.ai/state.json` | Resume-карта v4 |
| `.ai/INDEX.md` | Карта путей внутри бренда |

## Обязательные секции `index.html`

1. **Hero** — марка/модель, год, пробег/пакет ТО, CTA на отчёт и график  
2. **Характеристики** (`#specs`) — по СТС: VIN, двигатель, масса, категория  
3. **График ТО** (`#schedule`) — timeline ТО-0…N (км / годы)  
4. **Состав ТО** (`#detail`) — вкладки или блоки по пакетам  
5. **Расходники** (`#parts`) — масла, фильтры, тормоза, артикулы где есть  
6. **Подъёмник** (`#lift`) — пороги, тип подъёмника, оговорки  
7. **Отчёт** (`#report`) — факт работ/чеков (если уже обслуживались) или «ожидается»  

Nav-якоря должны совпадать с `id` секций.

## Именование slug

- lowercase, дефис: `exeed-rx`, `chery-tiggo-7-pro`, `haval-jolion`  
- Не дублировать бренд в корне репо — только под `brands/`

## Что не класть в публичный git без нужды

- Крупные аудиозаписи звонков (`.wav`)  
- Лишние PII сверх того, что уже на демо-странице  
- Пароли / токены (никогда)

## После добавления бренда

1. Ссылка в корневом `README.md`  
2. При желании — пункт в корневом `index.html` (каталог) или оставить редирект на главный демо  
3. Обновить `.ai` бренда: `hot_files`, `next`, публикация URL
