# Регламент ТО при пробеге ~42 000 км — EXEED RX (2023)

Источник ориентира: таблицы ТО дилеров EXEED RX + сервисная книжка линейки.  
Интервал: **каждые 10 000 км / 12 мес.** (что раньше).  
При **42 тыс. км** актуально **ТО-4 (40 000 км)** — если ещё не делали, это ближайший обязательный пакет.

Обозначения: **З** = замена, **П** = проверка (замена/ремонт по состоянию).

---

## Обязательные замены на ТО-4 (40 тыс.)

| Работа | Действие | Комментарий |
|--------|----------|-------------|
| Моторное масло + масляный фильтр | **З** | Каждые 10 тыс. / 1 год |
| Воздушный фильтр двигателя | **З** | С ТО-1 на каждом ТО |
| Салонный / фильтр вентиляции и кондиционера | **З** | На каждом ТО |
| Тормозная жидкость | **З** | **Каждые 40 000 км или 2 года** (что раньше) |

Свечи: на ТО-3 (30 тыс.) — **З**; на ТО-4 — только **П** (если на 30 тыс. уже меняли).

---

## Проверки на ТО-4 (типовой дилерский список)

- Уровни/состояние: моторное масло, ОЖ, тормозная, жидкость КПП  
- Подвеска, амортизаторы, рулевые тяги/наконечники/пыльники  
- Кардан / приводные валы, пыльники ШРУС  
- Тормозные колодки и диски (износ)  
- Шины: протектор, давление (в т.ч. запаска), момент колёсных болтов  
- Ремень навесных агрегатов  
- АКБ (напряжение), бортовая диагностика  
- Щётки и омыватели, кондиционер (работа)  
- Поддон / корпус КПП — течи  
- Трубопроводы топлива/тормозов, проводка  

Рекомендации вне «строки ТО», но по сроку/пробегу:

| Позиция | Когда |
|---------|--------|
| Топливный фильтр (внешний, если есть) | каждые **30 000** км (у части источников; в серв. книжке линейки часто «необслуживаемый» — сверить по вашему авто) |
| Очистка дроссельной заслонки | рек. ~**15 000** км |
| Развал-схождение | проверка ~каждые **20 000** км |
| Жидкость АКПП / DCT | **~60 000** км (не ТО-4) |
| ОЖ | ~**100 000** км / 3 года |
| Масло раздатки / заднего редуктора | по книжке часто «не требуется» или очень длинный интервал — только проверка уровня/течей |

## Расходники (ориентир для 2.0 SQRF4J20C ~249 л.с.)

Уточнять по VIN у поставщика; артикулы встречаются в разных написаниях.

| Позиция | Спека / объём | Артикул (ориентир) |
|---------|---------------|--------------------|
| Масло ДВС | **0W-20**, API SN/SP, ACEA **C5**; ~**6,0 л**; с завода часто Fuchs C5 0W-20 | — |
| Масляный фильтр | замена с маслом | `F4J20-1012010` / `480-1012010` / `4801012010` |
| Шайба сливной пробки | по необходимости | `481H-1002041` |
| Воздушный фильтр | | `151000151AA` |
| Салонный фильтр | | `ZJPCY5000055` (также встречаются др. коды, напр. `8119030BM02`) |
| Тормозная жидкость | **DOT 4** | по объёму системы при полной замене/прокачке |
| Свечи (если не меняли на 30 тыс.) | | `3707AAG` / семейство `F4J20-3707010` |

### КПП (для планирования, не обязательно на 40 тыс.)

| Узел | Ориентир |
|------|----------|
| 7DCT (740DHA/DHB и др.) | Sinopec **DCTF-GS**, ~5,0–5,2 л; замена ~**60 тыс.** |
| 8AT Aisin TG-81SC | ATF **AW-1**, порядка ~7 л; замена ~**60 тыс.** |
| Раздатка | Castrol SAF PD ~0,4 л |
| Задний редуктор | SAF CARBON MOD ~0,6 л |

Какая КПП стоит — по селектору/шильдику/диагностике (Prestige/Platinum чаще DCT; Premium/Flagship — часто 8AT).

## Чек-лист DIY (кратко)

1. [ ] Подтвердить отсутствие/наличие электропорогов → см. `porogi_lift.md`  
2. [ ] Закупить: масло 0W-20 C5 (~6 л), масляный фильтр, воздушный, салонный, DOT4  
3. [ ] Замена масла + фильтра; момент пробки / новая шайба  
4. [ ] Воздушный + салонный фильтры  
5. [ ] Замена тормозной жидкости с прокачкой (ABS — аккуратно; при отсутствии опыта лучше доверить)  
6. [ ] Осмотр тормозов, подвески, пыльников, течей  
7. [ ] Давление в шинах, перестановка колёс (рек. каждые 5–10 тыс.)  
8. [ ] Сброс индикатора ТО в мультимедиа (если есть)  
9. [ ] Зафиксировать дату/пробег/артикулы в сервисной книжке или файле учёта
